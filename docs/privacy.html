Application Android

L’APK ne déclare aucune permission Internet. Tous les fichiers sont inclus. La progression et la partie en cours sont stockées sur ton appareil, sans transmission par l’application. Les sauvegardes automatiques Android sont désactivées pour cette application. Désinstaller l’application ou effacer ses données supprime ta progression.

Démo web

La page et ses fichiers sont téléchargés depuis GitHub Pages. GitHub peut traiter des données techniques de visite selon sa propre politique. Le jeu n’effectue aucun appel réseau après son chargement. Les sauvegardes utilisent le stockage local de ce navigateur. Effacer les données du site supprime la progression.
